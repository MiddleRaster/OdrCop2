# OdrCop2
An ODR violations detector using LLVM/Clang's AST parser.  
There appears to be a paucity of ODR violation-detecting tools for MSVC, so I thought I'd write one.  

## How it works
The idea is to do a clean build of your project while logging to a binlog file; e.g.,  
```msbuild YourSolution.slnx /t:YourProject:Rebuild /p:Configuration=Debug /p:Platform=x64 /bl:binlog.binlog```.  
Then run BL2OC.exe on that .binlog file to generate a ```compile_commands.json``` file, which OdrCop2.exe consumes in order to use LLVM/Clang's AST, allowing ODR violations to be detected.


### What's completed

3. functions
4. UDTs (mostly)
